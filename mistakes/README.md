# 错题本使用说明

这里采用两种互补的记录：

- `index.csv`：每道错题一行，记录知识点、复习阶段和下次复习日期，便于筛选“今天该刷什么”。
- 每套试卷一个 Markdown 文件：保存可直接作答的题目；答案和解析折叠在题目下面，避免提前看到。
- `review_log.csv`：每次复习一行，保留结果和新的错误原因。不要覆盖旧记录。

## 复习规则

1. 到了 `next_review` 日期，先在纸上独立完成题目，再展开答案。
2. 做对且思路清楚：`stage` 加 1。下一次间隔依次为 3、7、14、30、60 天。
3. 做错、猜对或思路不清：`stage` 归 0，第二天再做。
4. 每次复习都在 `review_log.csv` 追加一行，同时更新 `index.csv` 中的 `last_review`、`next_review`、`stage` 和 `correct_streak`。
5. 连续正确 3 次后可把 `status` 改为 `mastered`，但仍建议每 60 天抽查一次。

## 推荐复盘标签

错误原因可以使用以下短标签，方便以后统计：

- `概念不清`：不知道该用哪个数量关系。
- `单位1错误`：把“比谁多/少”或“谁的几分之几”中的单位 1 找错。
- `运算选择错误`：乘法、除法或运算顺序选错。
- `计算错误`：方法正确，但通分、约分或乘除算错。
- `审题错误`：漏看“倒出”“剩下”“每千米/百千米”等关键词。
- `猜对/不确定`：答案碰巧正确，但不能清楚说明理由。

第一批题目统一从 `stage=0` 开始，首次复习日期为 2026-11-01。
